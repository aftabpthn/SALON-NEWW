# ADR Index

Architecture Decision Records (ADR) are stored in this folder.

## Active Records
- [0001: ADR record template](./0001-recording-decisions.md)

## How to add a new ADR
1. Copy `docs/adr/0001-recording-decisions.md`.
2. Rename with next number, e.g. `0002-decision-title.md`.
3. Update the status and references.
4. Add a short index bullet in this file.

## Purpose
- Preserve architecture decisions
- Capture context and trade-offs
- Provide a clear rationale trail for future changes
